## 2026-11-19 실제 장치와 Colab 연결

XIAO nRF52840 Sense + Expansion Base + SparkFun MAX30101에서 100 Hz RED PPG와 가속도 3축을 수집했다. 장치의 COM 포트를 고르고 Arduino 시리얼 모니터를 닫은 상태에서 앱의 예시 모드를 해제했다. START 명령으로 파형 표시와 로컬 저장을 확인한 뒤 Colab GPU 서버 주소와 비밀번호를 입력해 분석 응답을 받았다.

- 초기 펌웨어는 IMU 식별 실패, 이후 PPG 버퍼 밀림 반복으로 유효 행을 저장하지 못했다. 내장 IMU 주소 확인과 통신 대기 제한을 추가하고 MAX30101 FIFO의 대기 수·오버플로를 직접 읽도록 변경했다.
- 로컬 수집 세션 확인 시점에 7,308개 샘플이 저장됐다. 처음 7개 비중첩 10초 구간에서 샘플 번호와 시간 간격 검사를 통과했다.
- 별도 실시간 분석 세션에서 반환된 29구간 중 품질 RF의 재측정 25개, 움직임으로 제외 1개, AF 의심 1개, 비AF 2개였다. 정지로 분류된 28구간 중 25개가 품질 기준에서 제외됐다.
- 단일 세션의 동작 확인 결과다. ECG 정답이 없어 정확도·오탐률을 산출할 수 없다. 다음 분석은 품질 검사를 통과한 3구간과 재측정 25구간의 파형 비교다.

기본 저장 위치는 사용자 홈의 Capdyssey_recordings 아래 세션 폴더다. raw.csv에는 원시 신호가, events.jsonl에는 구간별 결과·사유·점수가 기록된다. 개인 실측 파일 및 서버 접속 정보는 각 PC에서 관리한다.

### IMU 초기화 보완 후 추가 실측 (2026-11-19)

IMU 식별 실패 이후 START 명령으로 전원을 재인가하고 초기화를 다시 시도하도록 변경했다. XIAO Sense의 내장 IMU 전원 핀은 Seeed 드라이버와 같은 H0H1 구동 모드를 사용한다.

추가 실측 세션에서 확인 시점 기준 RED PPG·가속도 12,241행이 저장됐고 Colab 응답은 12구간이었다. 움직임 제외 5개, PPG 품질 재측정 2개, AF 의심 4개, 비AF 1개였다. 센서-서버 연결의 동작 기록이며, 모델 분류의 정확도나 IMU 복구의 재현율을 측정한 실험은 아니다. 세션 로그는 펌웨어 버전을 기록하지 않는다.
