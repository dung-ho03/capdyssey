검증 환경: Windows / Python 3.12 / Gradio 5.49.1 / gradio_client 1.13.3 / pyserial 3.5. Gradio 내부의 이벤트 루프 정리 및 사용 예정 변경에 관한 경고가 발생했으나 테스트는 통과했습니다.

## 아직 검증하지 않은 항목

- 실제 XIAO 보드의 펌웨어 컴파일·업로드, 센서 배선, USB 수신 안정성, 타이밍 오차.
- 실제 손목 측정에서 IMU 임계값과 PPG 품질·AF 모델의 성능.
- 현재 컴퓨터에는 CUDA GPU가 없어, 원래 학습 모델의 GPU 추론 및 Colab GPU 실행을 이번 작업에서 재실행하지 않음.
- Colab 외부 공유 주소를 통한 PC와의 실제 인터넷 연결 및 장시간 운영.
- BLE 연결은 구현 범위에 포함되지 않음.

따라서 이 버전은 코드와 로컬 통신이 검증된 **장치 연결 전 연구용 통합본**입니다. 실제 장치·Colab 연결까지 검증 완료된 완제품이라는 뜻은 아닙니다.
