# 캡스톤 연구용 PPG 자료 모음

확인일: 2026-10-05. 연구 목표: PPG 심방세동(AF) 의심 구간 탐지와 움직임을 고려한 신호 품질 처리.

2026-10-10 후속: [통합 학습 1단계 조사](AF_INTEGRATED_TRAINING.md)를 참조하세요. 아래 장기 손목 v2의 제한 접근 기록 이후 공개 v3를 발견해 2명을 확보했습니다. 최신 확보·주석 확인 상태는 후속 문서에 있습니다.

**수집 완료:** 팀 로컬에 있던 기존 4종을 재검증하고 새 2종을 약 651.3MB(십진수) 확보했다. PTT는 66기록, BUT는 PPG 3,888기록(50명), 가속도 3,840기록이다. 새 자료의 공식 체크섬 27,328개가 모두 일치했고, 선택한 배포 파일의 누락과 헤더 기준 파형 파일 크기 오류가 없었다. 기존 218개 파일도 이전 저장 해시와 일치했다. 이는 무결성 검사이며 파형의 임상 품질 보증은 아니다.

## 자료 선택 기준

공식 연구팀·UCI·PhysioNet 배포처, 원 연구와 측정 방법, 정답 생성 근거, 참가자 구분 가능 여부, 이용 조건을 기준으로 선정했다. 공식 배포 자료라도 모든 파형이 깨끗하거나 우리 손목 센서에 동일한 성능을 보장하는 것은 아니다. 다운로드 체크섬은 파일 손상 여부를 확인하며, 임상적 정확도를 입증하지 않는다.

### 공식 출처 및 이용 조건

- **6종 리듬:** https://github.com/zdzdliu/PPGArrhythmiaDetection — 원 연구 https://doi.org/10.1161/JAHA.121.023555 . 저자 인용 요청은 있으나 명확한 별도 데이터 라이선스는 기존 조사에서 확인되지 않았다. 공개 다운로드와 학습·재배포 허가는 구분한다.
- **MIMIC PERform AF:** https://ppg-beats.readthedocs.io/en/latest/datasets/mimic_perform_af/ — 기존 원본 https://zenodo.org/records/15906524 . 저장된 MAT 내부 ODbL 1.0 안내를 따른다. 설명 웹사이트의 CC BY 문구와 데이터 라이선스를 혼동하지 않는다.
- **PPG-DaLiA:** https://archive.ics.uci.edu/dataset/495/ppg%2Bdalia — CC BY 4.0.
- **Wrist:** https://physionet.org/content/wrist/1.0.0/ — Open Data Commons Attribution 1.0.
- **BUT PPG:** https://physionet.org/content/butppg/2.0.0/ — CC BY 4.0, DOI https://doi.org/10.13026/tn53-8153 . 공식 페이지의 원 논문도 함께 인용한다.
- **PTT PPG:** https://physionet.org/content/pulse-transit-time-ppg/1.1.0/ — ODbL 1.0, DOI https://doi.org/10.13026/jpan-6n92 . 공식 페이지의 원 연구 인용을 따른다.

라이선스 원문과 출처를 가공 결과와 함께 유지한다. ODbL 자료에서 파생 데이터베이스를 외부 공유할 때는 해당 라이선스 의무를 검토한다. 이번 작업은 로컬 수집이며 공개 재배포하지 않았다.

## 팀에서 자료 받기

원본 데이터는 저장소에 포함하지 않는다. [다운로드 안내](../data/README.md)에 따라 각자 공식 배포처에서 받는다. `data/raw/`와 `data/processed/`는 Git에 올라가지 않는다.

이번 저장소의 다운로드 도구는 이용 조건이 명시된 5종만 지원한다. 6종 리듬은 위의 공식 링크 및 허가 확인 상태를 참고한다. 기존 팀 로컬 확보 수량과 공개 사용 허가는 서로 다른 정보다.

BUT PPG 품질 CSV: 좋은 품질 830개, 나쁜 품질 3,058개. 모두 나쁘다고 예측해도 약 78.7% 정확도이므로 클래스별 지표를 함께 보고한다. 공식 주석의 기준 채널은 빨간색 PPG이다.

## 실험 순서

1. 사람 단위로 학습·검증·시험을 나눈다. 겹치는 시간창이 다른 분할로 넘어가지 않게 한다. 정규화와 임계값 결정에는 시험 자료를 쓰지 않는다.
2. 이용 조건이 확인된 AF 자료로 기준 모델을 학습한다. 6종 리듬의 재사용 조건이 미확정이면 MIMIC PERform AF부터 시작한다.
3. BUT PPG에서 품질 분류를 개발하고, DaLiA·Wrist·PTT에서 ECG 기준 심박수 오차를 분석한다. 데이터마다 센서·측정 위치가 다르므로 결과를 별도로 보고한다.
4. 실제 장치의 PPG·IMU 수집 및 판단 보류 표시를 연결한다. 이때 새로운 센서에 대한 성능은 아직 입증되지 않았다고 구분한다.
5. AF 분류에는 민감도·특이도·F1·오탐률, 품질 분류에는 클래스별 성능, 맥박 추출에는 MAE와 판단 가능 비율을 보고한다. 보류를 늘려 오탐만 낮추는 결과는 개선으로 단정하지 않는다.

## 아직 필요한 자료

PPG·가속도·같은 시간의 AF 정답이 있는 자료가 있어야 IMU 추가에 따른 AF 탐지 개선을 직접 검증할 수 있다. 위 자료를 서로 임의로 붙여 이를 대체하지 않는다.

- Lithuanian 장기 기록 v2: https://zenodo.org/records/11242869 — 45명, 306일, 손목 PPG·가속도와 전문의 검토 AF 주석. 2026-10-05 공식 페이지 restricted 확인. 접근 승인 필요, 이번에 다운로드하지 않음.
- Simband/Pulsewatch: 기존 접근 제한으로 미확보. 이번에 계정 권한을 재확인하거나 신청·메일을 발송하지 않음.
- WESAD는 감정·스트레스 라벨 자료여서 이번 우선 수집에서는 제외. 이전 Zenodo 21095509 링크는 ECG 논문 PDF이며 PPG 원자료로 계산하지 않음.

이번 작업은 자료 확보·검증·선정이며 모델 학습이나 임상 성능 검증은 수행하지 않았다.
