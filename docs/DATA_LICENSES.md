# 데이터 이용 조건과 인용

확인 기준: 2026-10-05/06. 다음 내용은 공식 배포 고지와 팀이 확보한 원본의 라이선스를 정리한 것입니다. 각 라이선스 원문이 우선합니다.

| 자료 | 연구 사용 | 조건 및 원문 |
|---|---|---|
| PPG-DaLiA | 가능 | [UCI](https://archive.ics.uci.edu/dataset/495/ppg%2Bdalia), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). 저자·출처·라이선스·변경 여부 표시 |
| BUT PPG v2 | 가능 | [PhysioNet](https://physionet.org/content/butppg/2.0.0/), CC BY 4.0. DOI 10.13026/tn53-8153 및 원 논문 인용 |
| Wrist Exercise | 가능 | [PhysioNet](https://physionet.org/content/wrist/1.0.0/), [ODC-By 1.0](https://opendatacommons.org/licenses/by/1-0/). 출처·라이선스·원래 고지 유지 |
| PTT PPG v1.1 | 가능 | [PhysioNet](https://physionet.org/content/pulse-transit-time-ppg/1.1.0/), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). DOI 10.13026/jpan-6n92 |
| MIMIC PERform AF | 가능 | [Zenodo](https://zenodo.org/records/15906524). 원본 MAT에 데이터 ODbL 1.0, AF 주석 CC BY 4.0 명시 |
| 6종 리듬 | 사용 범위 미확정 | [저자 저장소](https://github.com/zdzdliu/PPGArrhythmiaDetection)는 연구 사용 시 인용 안내를 제공하나 명확한 학습·가공·재배포 라이선스를 확인하지 못함. 사용 금지로 확정된 것은 아님 |

ODbL은 사용·가공·공유를 허용하며 출처·고지 유지와 파생 데이터베이스의 공개 이용 시 동일조건 제공 등의 의무가 있습니다. 이것을 단순히 ‘인용만 하면 된다’거나 ‘모든 코드가 같은 라이선스가 된다’고 해석하지 않습니다. 다른 연구 자료의 라이선스를 팀 작성 코드에 일괄 적용하지 않습니다.

MIMIC AF 주석의 출처: Bashar (2020), https://doi.org/10.6084/m9.figshare.12149091.v1 . 데이터·주석의 원 출처를 함께 인용합니다. 일반 MIMIC 임상 자료 전체의 접근 조건과 이번 공개 PERform 파생 자료의 조건을 혼동하지 않습니다.

6종 리듬 저자에게 확인할 내용: 대학 비영리 캡스톤에서 공개 검증·시험 구간을 새로운 사람별 분할로 재구성하여 AF 분류 모델 학습·평가 및 결과 발표가 가능한지. 원본 재배포는 별도 질문입니다. 아직 저자에게 요청을 발송하거나 허가를 받지 않았습니다.

## 저장소의 공유 범위

이 저장소는 팀 작성 설명·다운로드 코드·무결성 검사 수치를 공유합니다. 데이터는 공식 배포처에서 받습니다. 다운로드된 파일의 라이선스와 고지를 보관하고 원본·가공 데이터는 기본적으로 Git에서 제외합니다. 비공개 저장소도 제3자 자료의 이용 조건을 없애지 않습니다.
