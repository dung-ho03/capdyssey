# AF/비AF 연구용 v1 — 2026-10-10

학습·평가·저장·새 파형 예측까지 실행되는 기준 모델입니다. 실제 학습을 완료했지만 오탐이 많으므로 성능 개발을 종결하거나 의료·제품 배포에 사용할 단계는 아닙니다.

## 실측 결과

MIMIC PERform AF 35명을 학습 21명, 검증 7명, 시험 7명으로 분리했습니다. 같은 사람이 서로 다른 집합에 들어가지 않습니다. 30초 비중첩 구간, 125→50Hz 변환, 구간별 평균/표준편차 정규화를 사용했습니다. 결측과 거의 평평한 구간만 제외합니다. AF 라벨은 원본 기록의 상태이며 각 30초 구간을 새로 판독한 정답은 아닙니다.

작은 1D CNN을 최대 20 epoch 학습하도록 설정했고 검증 손실이 5회 개선되지 않아 10 epoch에서 중단했습니다. 검증 손실로 선택한 5 epoch 모델, 사전 고정 임계값 0.5의 결과입니다. CPU에서 실행했으며 Colab 계정에서 직접 실행한 결과는 아닙니다.

| 시험 지표 | 결과 |
|---|---:|
| 시험 참가자 / 구간 | 7명 / 241개 |
| 정확도 | 65.1% |
| AF 민감도 | 75.3% (116/154) |
| 비AF 특이도 | 47.1% (41/87) |
| 균형 정확도 | 61.2% |
| ROC-AUC | 0.620 |
| 놓친 AF / 잘못 알린 비AF | 38 / 46 |

항상 AF라고 예측해도 구간 정확도는 63.9%이므로 정확도 65.1%만 강조하면 안 됩니다. 사람별 평균 점수로 평가하면 정확도 57.1%, ROC-AUC 0.417입니다. 같은 사람의 구간들은 독립 표본이 아니고 시험 참가자가 적습니다. 외부 데이터 검증은 없습니다.

이 분할의 시험 결과는 이전 1 epoch 동작 점검에서도 확인했습니다. 완전히 한 번도 보지 않은 시험셋이라고 주장하지 않습니다. 이번 실행에서는 기존 구조·seed 42·임계값을 유지하고 검증 손실로만 epoch를 선택했습니다. 이후 모델 개선은 학습/검증 자료 안에서 진행하고 최종 주장은 별도의 외부 시험 자료로 확인해야 합니다.

## 팀에서 사용하는 방법

- `models/af_mimic_v1/best_model.pt`: 실제 학습된 가중치. 다시 학습하지 않고 사용할 수 있습니다.
- 같은 폴더의 `metrics.json`, `history.json`, `split.json`, `data_audit.json`, `config.json`: 성능·학습·사람별 분할·제외 수·설정과 학습 코드 해시.
- `scripts/train_af.py`: 재학습. 결과 폴더가 이미 있으면 덮어쓰지 않습니다.
- `scripts/predict_af.py`: 원본 PPG 30초를 AF/non-AF 및 점수로 변환합니다.
- `notebooks/01_af_baseline_colab.ipynb`: 공식 데이터 자동 다운로드, 학습, 평가, Drive 저장, 예측 예제.

```sh
python -m pip install -r requirements-train.txt
python scripts/predict_af.py --checkpoint models/af_mimic_v1/best_model.pt --input my_ppg.npy --sampling-hz 125 --output prediction.json
```

`my_ppg.npy`는 1차원 원본 신호입니다. 125Hz라면 3750개, 100Hz라면 3000개의 값이 필요합니다. 이미 정규화·리샘플링한 자료를 원본이라고 넣지 마세요. 학습 자료는 125Hz 침상 PPG이므로 다른 주파수 입력을 처리할 수 있다는 사실이 다른 장치의 정확도를 보장하지 않습니다.

출력 `prediction`은 AF 또는 non-AF, `af_score`는 보정되지 않은 모델 점수입니다. non-AF는 모든 심장질환이 정상이라는 뜻이 아닙니다. 결측·평탄 신호·길이 오류는 판정 대신 오류를 반환합니다. 잡음이 있는 다른 파형은 통과할 수 있으므로 품질 AI는 별도로 필요합니다.

## 역할 분담과 다음 완료 조건

AF 담당자는 이 버전을 기준점으로 고정하고 검증 자료에서 오탐 원인을 분석합니다. 품질 담당자는 별도 품질 모델을 만들되 AF의 불규칙성을 잡음으로 제거하지 않는지 확인합니다. 통합 담당자는 두 모델에 같은 30초 구간 ID와 실제 샘플링 주파수를 전달하고, 품질 불충분/입력 오류 시 AF 결과 대신 재측정을 표시합니다. 본 버전은 품질 모델과 아직 통합되지 않았습니다.

성능 개발을 종결하려면 팀이 먼저 민감도·특이도 목표를 정하고, 추가 참가자/외부 자료에서 목표 달성 및 실제 손목 센서 일반화를 확인해야 합니다. 현재 시험셋을 반복적으로 보고 모델·임계값·seed를 고르는 방식은 피합니다.
