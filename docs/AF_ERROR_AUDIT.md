# 잠정 통합 모델 오분류 점검

Colab에서 고정된 8회차 모델로 시험 32,641구간을 다시 예측했다.
세 자료의 TP/FN/TN/FP가 기존 metrics.json과 모두 일치했다.
재학습, 임계값 조정, 정답 변경은 하지 않았다.

## 사람별 손목 오류

손목 시험 7명 23,051구간: FN 6,824, FP 4,935.
029는 잠정 비AF 2,000구간 중 1,814구간을 AF로 예측했다.
030은 잠정 AF 2,000구간 중 1,692구간을 놓쳤다.
006/020/026/030/039의 개인별 AUC도 약 0.49~0.55로,
한 참가자만 제외하거나 임계값만 옮기면 해결된다고 볼 근거가 없다.
007의 AF 구간은 2개뿐이므로 개인 민감도를 일반화하지 않는다.

## 전처리 경계 왜곡을 원본으로 재현

TP/FN/TN/FP에서 각각 2개씩 seed 20261013으로 무작위 선정한 8구간을 조사했다.
같은 시각의 원본 PPG를 다시 잘라 기존 전처리를 적용하자 저장된 모델 입력과
최대 절대 차이가 모두 0이었다. 8구간 모두 절대값 최대 지점은 첫 샘플이었다.

기존 `preprocess_window`는 큰 DC 기준값을 가진 원본을 그대로 `resample_poly`에
입력한 뒤 평균/표준편차로 정규화했다. 구간 밖 0 경계와 큰 기준값의 차이가
리샘플링 과정에서 경계 과도응답을 만들고, 이후 정규화로도 없어지지 않았다.
이는 원본의 잡음과 구별해야 하는 전처리 문제다.

진단 비교에서는 같은 원본의 평균을 **리샘플링 전**에 제거했다.
이 비교 파형으로 기존 모델을 평가하거나 성능 향상을 주장하지 않았다.

| 예시 | 기존 양 끝 에너지 비율 | 평균을 먼저 제거한 비교 |
|---|---:|---:|
| 026 FN, 026_006 | 98.79% | 13.92% |
| 029 FP, 029_000 | 99.87% | 3.81% |
| 030 TN, 030_005 예시 1 | 96.05% | 0.70% |
| 030 TN, 030_005 예시 2 | 96.81% | 4.24% |

양 끝은 총 500점 중 처음/마지막 10점씩, 총 4%의 표본이다.
이 수치는 8개 예시에 대한 진단으로 전체 데이터의 발생률이 아니다.
맞힌 구간에도 왜곡이 있어 오분류의 모든 원인이 이것이라고 단정하지 않는다.
앞서 계산한 8Hz 초과 성분 비율은 이 경계 왜곡을 포함하므로 원본 잡음 지표로
그대로 해석하면 안 된다.

## 정답·시간 연결 검사

손목 시험 23,051구간의 잠정 정답을 원본 ECG 주석에서 재계산해 전부 재현했다.
주석 시각을 -10/-1/+1/+10초 이동했을 때 반대 이진 정답으로 바뀐 구간은 없었다.
일부는 전환 경계에 걸려 제외됐다. 원래 안정적인 구간을 골랐기 때문에 예상되는
결과이며 물리적 ECG/PPG 동기화나 공식 0/1 코드 뜻을 증명하지 않는다.
제공 QRS와 원본 ECG를 나란히 그렸지만 의료진 재판독을 수행한 것은 아니다.
