# 맥박 특징과 정렬 진단 실험

## 변경 이유

전처리 구조 검사는 통과했지만 기존 손목 모델의 낮은 구별 능력은 해결되지 않았다.
필터링하지 않은 자기상관/주파수 특징도 손목 검증 AUC가 약 0.5에 머물렀다.
따라서 저주파 흔들림과 고주파 성분을 줄이고 맥박 간격 특징을 추가하는 실험을 한다.
0.5–5Hz, 3차 Butterworth, 양방향 필터와 반사형 경계 확장 100점은 이번 실험의
고정 공학 설정이며 이 자료에서 최적 또는 임상적으로 검증된 값이라고 주장하지 않는다.

## 입력과 비교

- 기존 10초/50Hz PPG, 동일한 피험자 분할, 세 자료 통합 학습을 유지한다.
- 중간 8초에서 양·음 방향의 봉우리를 각각 검출한다. 두 방향 특징을 모두 모델에
  제공하며 ECG나 정답을 보고 모델 입력의 방향을 선택하지 않는다.
- 간격 변동계수, 연속 간격 차이, 분위수, 검출 수, 검출 실패 표시 등을 추가한다.
- 충분한 봉우리를 찾지 못한 구간도 버리지 않는다. 실패 표시와 자료별/정답별
  실패율을 남겨 평가 대상에서 제외해 성능이 좋아 보이는 일을 막는다.
- 모델 학습·추론은 Colab GPU에서만 실행한다. SciPy 필터/봉우리 추출도 Colab에서
  실행되지만 CPU 배열 연산이다. 로컬 컴퓨터에서 데이터 처리·학습을 하지 않는다.
- 두 seed(42,43), 최대 20 epoch, patience 5, AdamW 0.0005를 사전에 고정한다.
- 모든 자료의 검증 특이도 80% 이상을 만족하는 공통 임계값에서 자료별 평균
  민감도를 최대화한다. 시험군은 읽지 않는다. 기존 검증군 재사용이라는 제한을 유지한다.

## ECG–PPG 진단 범위

학습/검증 피험자별·정답별 최대 12구간을 seed 42로 추출한다. 제공 QRS와
검출한 PPG 봉우리의 양방향 일치율을 비교한다. ±0.5초 범위에서 위상 차이를
탐색하고 0초와 ±10/±30초의 비교 구간을 함께 기록한다.
주기적인 파형은 다른 시간대도 일치할 수 있으므로 이 수치만으로 동기화를 확정하거나
시계를 자동 보정하지 않는다. ECG 간격 변동은 설명용으로만 저장하며 학습 특징에
절대 넣지 않는다. 전체 원본 파형이나 모든 박동을 임상적으로 판독하는 검사는 아니다.
