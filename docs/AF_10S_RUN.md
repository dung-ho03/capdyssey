# 10초 실행 결과와 통합 학습 미완료 상태

2026-10-10. **요청 목표는 세 자료 통합 학습이다. 이번 실행은 MIMIC만 사용한 10초 비교 기준이며 요청 목표를 완료하지 못했다.**

## 실제 수행

기존 전처리·학습 함수에 10초 입력을 추가하고 체크포인트에 입력 길이와 모델 이름을 저장했다. 예측 시 그 규격을 읽어 10초 모델에 30초 입력을 전달하는 오류를 거절한다. 기존 30초 체크포인트의 동작은 보존한다. 새 10초 모델은 기존 가중치를 재사용하지 않고 처음부터 학습했다.

로컬 Windows CPU에서 MIMIC 35명으로 실행했다. 동일 seed 42, 참가자 21/7/7 분할, 50Hz, 구간별 평균/표준편차 정규화, 작은 CNN, 최대 20 epoch, 검증 손실 5회 미개선 종료를 적용했다. 최적 epoch는 2, 종료는 7이다. 원본 체크섬 확인과 13개 테스트가 통과했다. 10초 학습·예측 일치 및 길이 혼용 거부 테스트를 포함한다.

```sh
python scripts/download_data.py mimic_af
python scripts/train_af.py --seconds 10 --output runs/mimic10 --epochs 20 --seed 42
```

## 실측 성능

| 시험 10초 구간 | 값 |
|---|---:|
| 구간 수 | 776 |
| 정확도 | 44.85% |
| AF 민감도 | 29.39% |
| 비AF 특이도 | 68.98% |
| 균형 정확도 | 49.18% |
| AUROC | 0.5702 |
| TP / FN / TN / FP | 139 / 334 / 209 / 94 |

낮은 AF 민감도로 현재 분류 성능은 부족하다. 10초 변경만으로 성능이 개선되었다고 주장하지 않는다. 기존 30초 결과와는 창 길이·제외 구간·실행 환경 등이 달라 길이 효과만 분리한 비교가 아니다. 같은 시험 참가자들은 기존 개발에서 평가한 적이 있으므로 독립적인 새 최종 시험이라고 부르지 않는다. 시험 결과를 보고 임계값·seed를 다시 선택하지 않았다. 품질 AI 연결과 손목 외부 검증은 미실행이다.

## 세 자료 통합이 아직 안 된 이유

- 6종: 10초 입력과 5=AF/0~4=비AF 매핑은 확인했으나 1단계에서 기록한 학습·파생물 공유 범위 확인은 미완료다. 이번 실행에서는 사용하지 않았다.
- 손목 v3: 주석 값의 정의와 QRS/RR 연결 규칙을 찾지 못했다. 0/1도 검증되지 않은 정답으로 임의 적용하지 않았다. 2명만 확보한 상태다.
- 따라서 코드 설정과 결과에는 `datasets_used=[mimic_perform_af]`, `three_dataset_integrated=false`를 명시했다. [통합 준비 상태](../data/af_integration_status.json)는 진행 기록이며 승인 또는 라벨 정의를 대신하는 설정이 아니다.

다음 필수 작업은 6종의 사용 범위 및 손목의 코드북 확인이다. 확인 이후 참가자별 분할, 손목 시간 연결, 10초 공통 어댑터, 자료별 표본 균형을 구현하고 세 자료로 새 실험을 실행해야 한다. 아직 통합 로더나 세 자료 학습 실행이 완료된 것으로 표현하지 않는다.
