# MIMIC + 6종 PPG 주 모델

손목 자료의 낮은 구별 능력과 미해결 품질·정렬 문제 때문에, 2026-10-14부터
주 모델의 학습/선택/시험은 MIMIC과 6종으로 제한한다. 손목 원본과 기존 실험은
보존한다. 원본 데이터 전체가 잘못되었다는 결론이나 손목 일반화 성공 주장은 하지 않는다.

## 고정 절차

1. 검사 완료한 `provisional_centered_v2` 중 두 자료만 사용한다. 기존 피험자 분할 유지.
2. 10초/50Hz/500점, 평균 제거 후 리샘플링, 표준화, 기존 맥박·주파수 특징 유지.
3. 손목을 제외한 학습군으로 특징 평균/표준편차와 source/class/person 가중치를 계산한다.
4. Colab GPU에서 seed 42/43, 최대20epoch, patience5, AdamW 0.0005로 학습한다.
5. 검증군에서 두 자료 각각 특이도80% 이상인 공통 임계값 중 평균 민감도 최대값 선택.
6. 검증 평균 민감도가 높은 seed 선택(동률이면42). 체크포인트 해시와 임계값을 먼저 저장한다.
7. 고정한 모델로 기존 시험군 평가. 시험 결과를 보고 임계값이나 seed를 바꾸지 않는다.

이는 기존 검증/시험 분할을 재사용한 개발 평가다. 시험군은 과거 다른 실험에서 이미
확인했으므로 완전히 독립된 외부 검증 또는 임상 검증이라고 부르지 않는다.
손목 포함 이전 실험과 모델·분할·최적화 설정은 같지만 학습 자료 수가 줄어 epoch당
업데이트 수와 임계값 제약 대상이 달라진다. 순수하게 동일한 계산량의 인과 비교는 아니다.

## 실행과 저장

`python scripts/af_pulse_experiment.py --base <Drive 경로> --two-sources`

완료 후 `python scripts/finalize_two_sources.py --base <Drive 경로>`.
모델과 결과는 Drive `models/main_two_sources_v1`에 저장한다.
`candidate/model.pt`, `frozen_selection.json`, `test_report.json`이 연구 후보 산출물이다.
입력은 ECG 없이 PPG만 사용한다. 전처리된 입력 추론은 `finalize_two_sources.Predictor`.
원본 PPG는 `prepare_af_centered.centered_window(raw, fs)`로 처리한 후 전달한다.
의료 진단용 배포 모델이 아니며, 낮은 품질 신호에 대한 검증된 판정 보류 기능은 아직 없다.

팀 실행 노트북: [08_main_two_sources_colab.ipynb](../notebooks/08_main_two_sources_colab.ipynb).
실행 코드 버전은 `6b0c344`로 고정했다.

## Colab T4 완료 결과

전체 분할 합계 MIMIC 4,115구간/35명, 6종 46,827구간/91명.
총 50,942구간은 학습·검증·시험 합계이며 전부를 학습한 수가 아니다.
손목 구간은 특징 정규화·학습·검증 선택·시험 모두에서 제외했다.

검증 평균 민감도로 seed42/epoch18, 공통 임계값0.286을 선택했다.
seed43/epoch12/임계값0.318의 검증 민감도는 MIMIC97.70%, 6종92.08%였고,
두 자료 모두 검증 특이도80% 이상이었다. 시험군으로 seed를 선택하지 않았다.

| 분할 | 자료 | 구간 수 | TP/FN/TN/FP | 민감도 | 특이도 | AUC |
|---|---|---:|---|---:|---:|---:|
| 검증 | MIMIC | 838 | 469/9/331/29 | 98.12% | 91.94% | 0.9730 |
| 검증 | 6종 | 11,118 | 2230/169/6978/1741 | 92.96% | 80.03% | 0.9394 |
| 기존 시험 | MIMIC | 776 | 466/7/212/91 | 98.52% | 69.97% | 0.8869 |
| 기존 시험 | 6종 | 8,814 | 2498/255/4897/1164 | 90.74% | 80.80% | 0.9347 |

**두 자료 각각 민감도90%·특이도80% 목표는 미달성이다.** MIMIC 시험 비AF
303구간 중91구간이 AF로 판정됐다. 민감도는 높지만 이 오탐 때문에 배포 완료로
표시하지 않는다. 시험 결과를 보고 임계값을 바꾸지 않았으며, 개선 실험에는
참가자별 검증과 오탐 원인 분석이 필요하다.

이전 통합 모델(seed42)의 검증 민감도 MIMIC95.40%/6종90.20%보다 상승했지만,
특이도는 95.56%/81.08%에서 91.94%/80.03%로 낮아졌다. MIMIC 검증 AUC도
0.9948에서0.9730으로 낮아졌다. 따라서 손목 제외가 모든 지표를 개선했다거나
손목이 기존 모델을 해쳤다고 단정할 수 없다. 손목을 보류한 주된 이유는
해당 자료의 품질·정렬·잠정 라벨 해석 문제를 주 모델과 분리하기 위해서다.

저장 체크포인트를 T4에서 재로딩하고 6종 검증 표본64개의 예측을 재현했다.
최대 확률 오차1.79e-7로 통과했으며, 평탄·NaN·길이 오류 입력3종은 모두 거부했다.
`candidate/reload_check.json`에 검사 결과를 저장했다. 이는 검증된 신호 품질
분류기를 구현했다는 뜻은 아니다.
