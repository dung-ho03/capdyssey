# 개발 순서와 실험 파일

지금 시제품을 실행하려면 [첫 화면의 바로 실행하기](../README.md#바로-실행하기)를 보세요. 아래 번호는 팀이 어떤 문제를 확인하고 다음 실험으로 넘어갔는지 설명하는 순서입니다.

| 단계 | 팀이 확인한 내용 | 관련 파일 |
|---|---|---|
| 01 자료 준비 | 파형과 정답의 출처, 이용 조건, 원본 무결성을 확인했습니다. | [자료 목록](DATASETS.md) · [다운로드 방법](../data/README.md) |
| 02 첫 AF 모델 | MIMIC으로 30초 모델을 학습하고 과적합과 오탐을 확인했습니다. 6종 리듬과 비교하기 위해 10초 입력도 시험했습니다. | [30초 학습](../notebooks/01_af_baseline_colab.ipynb) · [10초 비교](AF_10S_RUN.md) |
| 03 장기 손목 자료 탐색 | 39명 자료까지 활용하려고 세 자료를 맞췄습니다. 주석 코드와 시간 정렬에 불확실성이 있어 최종 학습에서는 손목 자료를 제외했습니다. | [세 자료 탐색 노트북](../notebooks/실험기록/03_장기손목_세자료_통합탐색.ipynb) · [잠정 라벨 실험](AF_PROVISIONAL_EXPERIMENT.md) |
| 04 두 자료로 AF 모델 고정 | MIMIC과 6종 리듬으로 참가자를 나누어 학습하고, MIMIC에서 비AF가 AF로 표시된 사례를 조사했습니다. | [두 자료 학습](../notebooks/08_main_two_sources_colab.ipynb) · [오탐 분석](AF_FALSE_POSITIVE_AUDIT.md) |
| 05 신호 품질 모델 비교 | BUT PPG로 품질을 판별하는 CNN과 RF를 비교했습니다. 파일명의 초안·수정본은 팀의 실험 버전을 뜻합니다. | [CNN 초안](../notebooks/실험기록/05a_BUT_품질CNN_초안.ipynb) · [CNN 수정본](../notebooks/실험기록/05b_BUT_품질CNN_수정본.ipynb) · [CNN 재현용 원본](../02_but_ppg_quality_cnn_본실행_수정본11.ipynb) · [RF 재현용 원본](../PPG_quality_RF_improved.ipynb) |
| 06 RF와 AF 모델 연결 | 품질 미달을 재측정으로 분리하고, 필터 적용 전후의 오탐·전체 AF 검출률·판정 비율을 비교했습니다. | [통합 비교](QUALITY_AF_INTEGRATION.md) · [최종 RF 평가](QUALITY_AF_V2.md) · [학습된 모델](../models/quality_af_v2_final/) |
| 07 시제품과 실시간 검증 | 초기에는 USB로 PPG를 CSV에 기록했고, 이후 PPG와 3축 가속도를 함께 보내 움직임 검사부터 Colab 판정까지 연결했습니다. | [초기 PPG 기록 도구](../scripts/log_ppg.py) · [실시간 설치 방법](../models/Capdyssey_realtime_v1/README.md) · [테스트와 실측 결과](../models/Capdyssey_realtime_v1/검증결과.md) |

최상위 폴더의 CNN·RF 노트북 두 개는 [팀 모델 재현 코드](../scripts/train_team_quality.py)가 기존 경로에서 읽고 파일 해시를 확인하는 원본입니다. 번호가 붙은 Colab 실행본은 [notebooks](../notebooks/), 팀의 이전 탐색 노트북은 [실험기록](../notebooks/실험기록/)에서 찾을 수 있습니다.
