# AF/비AF 통합 학습: 목표·결정 이유·진행 기록

업데이트: 2026-10-10. 현재: **1단계 조사 결과 기록, 미확인 항목 있음. 통합 학습 미실행.**

후속 실행: [10초 MIMIC 비교 기준](AF_10S_RUN.md)을 학습·검사했다. 통합 방향은 10초로 정했으며, 아래 10초 후보 설명은 그 결정 이전 조사 기록이다. 통합 데이터 어댑터와 세 자료 재학습은 미완료다. 기존 30초 모델은 보존한다.

## 목표와 추진 이유

MIMIC PERform AF, 6종 리듬 PPG, 장기 손목 PPG의 확인된 정답으로 학습하여 새로운 사람의 PPG만 입력해 AF/비AF를 예측하는 것이 목표다. ECG와 전문가 주석은 학습·평가 정답의 근거이며 배포 모델의 필수 입력은 아니다. 비AF에는 다른 부정맥이 포함되므로 비AF를 건강으로 표현하지 않는다.

기존 MIMIC 초기 모델에서 과적합 징후와 높은 비AF 오분류율을 확인했다. 참가자·리듬·센서 환경의 다양성을 늘려 개선 여부를 평가한다. 데이터 양 증가가 성능 향상을 보장하거나 부족한 데이터가 유일한 원인으로 입증된 것은 아니다. [기존 학습 기록](../models/af_mimic_v1_colab/history.json), [평가](../models/af_mimic_v1_colab/metrics.json), [확장 이유](AF_DATA_EXPANSION.md).

이용 조건 미확인과 정답 코드 미확인은 자료의 임상적 신뢰성이 없다는 판단이 아니다. 새 PPG 예측에는 정답이 필요 없지만 추가 학습과 정답 대비 성능 평가에는 정확한 정답 연결이 필요하다. 이번에는 임의 정답 생성·재학습을 수행하지 않았다.

| 3 | 심실빈맥(VT) | 0: 비AF | 2,179 |

비AF 합계 30,658 / AF 16,169. 원래 리듬 코드를 보관해 리듬별 오분류를 평가한다. 로컬 91개 MAT 모두 `ppgseg` 행 수와 `labels` 수가 일치하고 각 행은 1,000 샘플이다. 공식 valid/test 목록의 파일 누락·추가·목록 간 중복이 없었다. 논문 전체 228명을 확보한 것으로 세지 않는다. 공개된 원 연구 검증·시험 자료를 우리 학습에 사용한다면 별도 연구 분할로 명시하고 원 논문 시험 결과와 직접 동일 조건 비교를 하지 않는다.

### 30초 입력 계획 수정이 필요한 이유

앞선 통합 계획은 모든 자료를 30초로 맞춘다고 설명했지만 6종 공개 파일은 이미 10초로 분할되어 있다. 확인한 MAT에는 `ppgseg`, `labels`만 있고 구간 간 연속성을 확정할 시간 정보가 없다. 임의의 세 구간을 이어 붙이거나 반복·제로패딩하여 30초로 만들지 않는다.

통합 v2의 우선 설계 후보는 **10초·50Hz·500 샘플**이다. 긴 MIMIC/손목 기록은 연속된 10초로 자르고, 6종 자료는 원래 10초를 유지한다. 이는 3단계에서 확정할 설계이며 아직 구현하지 않았다. 기존 30초 v1의 가중치와 예측 인터페이스를 그대로 통합 v2라고 부르지 않고 재학습한다. MIMIC 비교 기준도 동일한 새 입력 길이로 다시 만들어 길이 변경과 자료 추가 효과를 구분한다. 30초 단위 결과가 필요하면 실제로 연속된 10초 출력의 집계 규칙을 별도로 검증한다.

### MIMIC 확인 범위

원본 2개 MAT에서 35개 고유 참가자, 125Hz, 각 150,001 샘플을 확인했다. 마지막 끝점 샘플 처리를 전처리 규칙에 명시한다. 원본의 기록 수준 상태를 사용하며 각 짧은 창을 새로 전문의가 판독한 것처럼 표현하지 않는다. 기존 시험 7명은 이미 여러 개발 실행에서 평가되었으므로 완전히 새로운 외부 최종 시험 집합으로 주장하지 않는다.

### 장기 손목 자료 확인 범위

공식 v3 설명은 ECG 주석을 박동 단위라고 설명한다. 로컬 006·039에서는 주석 수 = RR 수 = QRS 수 − 1이며 RR 값은 QRS 차이/500과 일치했다. 그러나 이것만으로 주석이 앞/뒤 어느 박동 또는 구간에 붙는지 확정할 수 없다. 두 파일에 0, 0.25, 0.5, 1이 있으며 파일 속성에는 수치형 정보만 있고 코드 범례는 없었다. **현재 모든 값의 의미와 연결 규칙을 확인 대기하며, 임의 이진화하지 않는다.**

[기존 파일 검증](verification-longterm-af-2026-10-10.json)과 [추가 시간·입력 변환 검사](verification-af-alignment-2026-10-10.json)를 참조한다. 시작일·시각과 명시된 샘플링 속도 기준 ECG와 겹치는 PPG는 006 약 8.84시간, 039 약 116.93시간이다. 16개 기록의 첫 30초씩 기존 전처리 함수로 변환되는 것을 확인했지만 전체 품질 또는 새 10초 파이프라인 검증은 아니다.

## 남은 확인 질문과 완료 기준

1. **6종 저자 확인:** 대학 비영리 연구에서 공개 valid/test 자료를 참가자별로 재분할하여 AF/비AF 모델을 학습하고 결과·모델을 공유할 수 있는지, 적용 조건은 무엇인지. 공개 README의 연구 인용 안내는 확인했지만 구체적인 범위를 단정하지 않는다.
2. **손목 v3 저자/코드북 확인:** 0/0.25/0.5/1 각각의 의미, 주석 인덱스와 QRS/RR의 연결 방식, 불확실·잡음·전환 구간 규칙은 무엇인지.

이번에 저자에게 메시지를 보내거나 허가를 받지는 않았다. 위 항목을 확인하기 전에도 참가자 목록·전처리 인터페이스 설계는 가능하나, 세 자료 모두의 정답과 사용 범위가 확인됐다고 표시하거나 통합 재학습을 실행하지 않는다. 39명 전부 확보·확인 역시 아직 완료하지 않았다.

원본·가공 데이터는 데이터셋별 출처와 라이선스를 보존하며 Git에 올리지 않는다. 서로 다른 동일조건 라이선스를 한 가지로 일괄 변경하지 않고, 합친 데이터나 모델의 외부 공개 조건은 공개 전에 별도로 확인한다.
