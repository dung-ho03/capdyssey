# 전처리 재점검

## 이유

Colab의 후속 주석 탐색 셀은 ECG 주파수를 100Hz로 가정했지만 기존 학습용
전처리는 500Hz를 사용한다. 주석 코드의 평균을 AF 비율로 해석할 근거도 부족하다.
탐색 셀의 오류가 학습 데이터로 들어갔다는 증거는 아직 없다. 최종 모델 확정을
보류하고 원본부터 단계별로 재점검한다. 기존 데이터와 결과는 변경하지 않는다.

## 1단계: 원본 및 시간 기준

실행 위치: Colab. `scripts/audit_preprocessing_step1.py --base <Drive 데이터 경로>`

- 세 자료 원본 파일 수, 손목 39명 ECG/PPG 78개 파일 누락·추가 확인
- 39명 ECG/PPG의 작은 메타데이터 수집
- 주석·QRS·RR 길이, 유한값, 증가 순서, ECG 범위 확인
- QRS 차이와 RR 비율 비교 및 100/500Hz 가정의 오차를 함께 기록
- ECG·PPG 시작 시각과 개별 기록 길이 수집
- 500/100Hz 가정 아래의 겹치는 시간을 조건부로 기록

RR 일치만으로 공식 샘플링 주파수나 물리적 동기화가 입증되는 것은 아니다.
원본 코드값은 그대로 기록하며 AF 비율이나 특정 리듬 이름으로 해석하지 않는다.
파일 전체 체크섬·신호 품질 전수 검사는 이 단계에 포함되지 않는다.

보고서는 Drive `audits/preprocessing_step1/report.json`에 저장한다.
누락/읽기 실패 시 보고서를 남기고 실패로 종료한다. 그 외 이상 항목 역시
후속 진행 전에 검토한다. 완료 출력은 학습 승인이나 임상 정답 확인을 뜻하지 않는다.

## 현재 상태

2026-10-14 확인: Drive 재연결 후 1단계 원본 검사 실행 완료.

- MIMIC 원본 2개, 6종 원본 91개, 손목 ECG/PPG 원본 78개 확인.
- 손목 39명 모두 읽기 완료. 누락, 주석/QRS/RR 길이 오류, 비유한 주석·QRS·RR,
  QRS 순서 오류, ECG 시작 시각 누락 없음.
- 003번 QRS가 ECG 범위를 벗어남. PPG 시작 시각이 없는 기록 3개 발견.
- QRS 차이/RR 비율은 전원 500. 500Hz 계산의 최대 RR 오차
  `5.684341886080802e-14`초, 100Hz 계산의 최대 오차 `7201.472`초.
- [공식 v3 설명](https://zenodo.org/records/23187681)에서도 ECG 500Hz,
  PPG 100Hz를 확인했다. 100Hz를 ECG에 적용한 후속 탐색 셀의 시간 통계는 폐기한다.
- 작은 메타데이터 수집은 참조형 헤더의 내용을 모두 해석하지 않는다.
  주파수 근거는 공식 설명과 QRS/RR 수치 일치이며 헤더를 완전 해독했다는 뜻이 아니다.

2단계 `audit_prepared_bundle.py`는 기존 525개 학습 파일의 SHA256, 배열 크기,
유한값, 정규화, 피험자 분할, 손목 원본 정답 재현 및 기록 경계를 검사한다.
오류가 있으면 보고서를 남기고 중단한다. 임상 정답 의미와 물리적 정렬까지
입증하는 검사는 아니다. 기존 모델 최종 확정과 추가 학습은 진행하지 않는다.

1단계 결과를 확인한 뒤 파일 무결성, 파형 품질, 시간 정렬 및 실제 학습 구간의
정답 재현을 별도 단계로 진행한다.

첫 검사에서 6종의 시각 NaN을 오류로 판정한 것은 **검사 코드의 오류**였다.
6종은 독립된 조각으로 연속 시각을 제공하지 않으며 기존 전처리가 이를 NaN으로
보존한 것이 맞다. 검사 코드를 자료별로 수정했다. 손목/MIMIC의 시각 검사는 유지하고,
6종은 원본 파일 SHA256과 원본 조각 번호를 확인하여 원본 리듬 코드 5=AF 매핑을
대조했다. 수치나 라벨을 바꿔 오류를 숨기지 않았다. 실패 보고서도 Drive에 보존했다.
