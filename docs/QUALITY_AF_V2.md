# 품질 RF + AF 통합 연구용 v2

2026-11-10 사용자가 제공한 Colab 출력 기준. MIMIC+6종 AF 모델은 고정하고, BUT 품질 RF에 원본 손상 특징 9개를 추가했다. BUT 검증군에서 기존 RF와 동일한 불량 차단율 83.76%를 만족하는 기준 0.2739494799615767을 선택했다. AF 임계값은 기존 저장 체크포인트 값(약 0.286)을 그대로 사용한다. 원래 RF의 맥박 특징은 유지했다.

## 왜 변경했는가

기존 RF는 MIMIC 검증군에서 AF 67개를 제외했다. 진폭·리듬 특징을 삭제한 실험은 좋은 신호까지 더 많이 제외하는 사례를 보여 그대로 채택하지 않았다. 원본의 평탄 구간 길이·비율, 상대적 단차, 느린 변동, 국소 진폭 비율을 특징으로 추가했다. 이는 파형 복원이 아니라 품질 분류의 입력 정보 추가다. 규칙으로 특정 파형을 자동 삭제하지 않는다.

불량 의심 신호도 AF 라벨일 수 있으므로 전체 AF 검출률 하락만으로 품질 오류를 판단하지 않는다. 32개 그림의 잠정 보조 검토는 학습·임계값 선택에 사용하지 않았다. 원본 신호를 실제로 판독할 수 있는지에 관한 독립 검토는 아직 충분하지 않다.

## 고정 후보의 개발 평가

아래는 반복 사용했던 시험 참가자 결과이며 독립 시험 또는 임상 검증이 아니다. TP/FN/TN/FP는 판정한 구간의 수다. 전체 AF 검출률은 재측정 AF까지 분모에 포함한다. 판정한 구간의 특이도 분모에서는 재측정 비AF를 제외한다.

| 자료·방식 | 전체 AF 검출률 | 판정 구간 민감도 | 판정 구간 특이도 | 오탐 수 | AF 재측정 | 비AF 재측정 | 판정 비율 |
|---|---:|---:|---:|---:|---:|---:|---:|
| MIMIC 필터 없음 | 98.52% | 98.52% | 69.97% | 91 | 0 | 0 | 100% |
| MIMIC 기존 RF | 95.56% | 98.91% | 79.84% | 51 | 16 | 50 | 91.49% |
| MIMIC v2 RF | 96.62% | 98.70% | 79.84% | 51 | 10 | 50 | 92.27% |
| 6종 필터 없음 | 90.74% | 90.74% | 80.80% | 1,164 | 0 | 0 | 100% |
| 6종 기존 RF | 90.23% | 90.79% | 80.79% | 1,146 | 17 | 94 | 98.74% |
| 6종 v2 RF | 90.63% | 90.76% | 80.74% | 1,163 | 4 | 23 | 99.69% |

MIMIC에서는 기존 RF와 같은 오탐 수에서 AF 5개를 더 검출했다. 필터 없는 모델에 비하면 오탐 40개 감소와 함께 AF 검출도 9개 감소했다. 6종에서는 기존 RF 대비 AF 11개를 더 검출하지만 오탐 17개가 늘었다. 필터 없음 대비 오탐 감소는 1개에 그친다. 전반적으로 모든 지표가 좋아진 모델이라고 표현하지 않는다.

MIMIC 판정 구간 특이도는 **79.84%**로, 두 자료에서 민감도 90%·특이도 80%를 모두 만족한다는 기존 목표는 아직 달성하지 못했다. 80%로 반올림해 목표 달성이라 보고하지 않는다.

BUT 검증 양호 통과율은 같은 불량 차단율에서 기존 62.75%, v2 58.82%였다. 품질 분류 자체의 전면적 우수성은 입증하지 못했다.

CNN 학습·연결 전처리는 BUT 학습/검증 3,152개에서 차이 0이었다. MIMIC·6종 검증 입력의 평탄 처리에 따른 0 파형 변환도 0개였다. 이는 모든 CNN 구현이나 기기 전이 문제가 없다는 뜻은 아니다. 현재 v2 연결 경로에는 CNN을 사용하지 않는다.

## 실행 규격

`raw PPG 10초 → 품질 RF → 통과하면 기존 AF 모델 → AF / non_AF`

- 모델에 미리 정규화한 파형을 넣지 않는다. 실제 샘플링 주파수와 단일 원본 채널을 전달한다.
- 품질 판정은 기존 30 Hz 처리 + 원본 손상 특징, AF는 평균 제거 후 50 Hz 리샘플링·정규화한 500개 샘플을 사용한다.
- 품질 미달은 `status=remeasure`, `label=None`, `af_score=None`이다. 비AF로 처리하지 않는다.
- 입력은 정확히 10초여야 한다. 길이/주파수 오류는 명시적으로 예외를 발생시킨다. 누락·상수 신호는 재측정이다.
- RF는 CPU, AF 추론은 Colab GPU다. 점수는 임상적으로 보정된 확률이라고 주장하지 않는다.
- 품질 임계값은 **manifest.json의 quality_threshold**를 사용한다. 학습 joblib에 저장된 BUT 균형정확도 기준 0.195414를 실수로 적용하지 않는다.
- 현재 외부 센서, 손목 장기 자료, 새 참가자 집단에서의 유효성은 확인되지 않았다.
