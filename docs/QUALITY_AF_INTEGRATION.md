# BUT 품질 모델과 AF 모델 연결 실험

2026-10-16: 임계값 강화만으로 MIMIC 오탐과 6종 AF 민감도를 함께 만족하지 못해 입력 품질 필터를 비교한다. 기존 AF seed42/0.286은 고정하고 없음/RF/CNN을 각각 비교한다. 둘을 연속 적용하지 않는다.

최신 main과 원격 브랜치·릴리스 확인 결과 품질 모델의 노트북과 실행 출력은 있으나 학습된 RF/CNN 파일은 없었다. Drive의 프로젝트 예상 폴더 검색에서도 발견되지 않았다. 따라서 팀 노트북 코드를 Colab에서 재실행한다. 이는 팀원의 기존 가중치를 복구한 것이 아닌 재현 학습이다.

[Colab에서 실행](https://colab.research.google.com/github/dung-ho03/capdyssey/blob/main/notebooks/10_quality_af_colab.ipynb)

- 원본 동일 10초에서 품질 30Hz와 AF 50Hz 입력을 각각 생성한다. AF 입력이 기존 저장 파형과 일치하는지 검사한다.
- RF의 진폭 특징과 CNN의 flat 기준은 센서 단위에 의존한다. 이 실험은 다른 장치에 대한 적용성 검사이며 품질 정답 검증은 아니다.
- CNN은 팀 수정본의 참가자별 CV, 확률 보정, 최종 학습 절차를 실행한다. RF는 팀 코드의 참가자 분리 holdout을 사용한다. BUT 심박수 측정 품질 정답을 AF 정답과 혼동하지 않는다.
- RF 및 전처리는 Colab CPU, CNN과 AF는 Colab GPU. 로컬 학습 없음.
- 품질 기준 및 AF 임계값을 이번 AF 시험 결과에 맞춰 변경하지 않는다. 통과 구간 민감도/특이도와 전체 AF 검출률, 오탐 수, AF/비AF 보류율, 커버리지를 함께 저장한다.
- 판정 보류를 TN이나 비AF로 처리하지 않는다. 고정 모델에 필터만 붙이면 전체 AF 검출 수가 증가할 수 없다. 통과 구간 성능과 오탐/보류의 교환을 확인하는 단계다.
- Longterm은 이번 실험에서 제외. 품질 및 라벨·시간 대응 검토 후 별도 잠정 평가한다.
- 원자료와 모델은 Drive에 저장. 기존 시험군 재사용 개발 평가이며 독립/임상 검증이 아니다.

저장 위치: `Capdyssey/af_integrated/models/team_quality_reproduction_v1/` 및 `models/quality_af_fixed_v1/`. 다운로드는 공식 체크섬으로 검증한 BUT PPG·정답 파일 7,777개만 사용한다. 완료된 다운로드/모델/평가 shard를 재사용한다. CNN 학습 중단 시 해당 CNN 학습은 다시 시작하며 epoch 단위 완전 재개는 지원하지 않는다.

현재 코드 준비 및 지표 분모·빈 통과 집합 검사 완료. 실제 연결 성능은 Colab 실행 결과가 나온 뒤 추가한다.
