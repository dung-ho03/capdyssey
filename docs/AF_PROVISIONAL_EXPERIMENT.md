# 세 자료 통합 잠정 실험 — 2026-10-13

## 변경 이유

사용자가 독립 재사용 코드에 근거한 잠정 실험을 승인했다. 공식 코드북 확인을
기다리는 정식 검증 경로는 유지하고, 별도의 명시적 실험 경로를 추가한다.
추가 자료가 일반화에 도움이 되는지는 평가로 확인한다. 기존 모델의 과적합이
입증되었거나 세 자료 통합으로 성능이 좋아졌다고 미리 주장하지 않는다.

## 라벨과 한계

- 손목 원본 `0→비AF`, `1→AF`를 잠정 가정한다. 공식 v3 대응표 확인은 아니다.
- `0.25`, `0.5`, 비유한 값, 전환 구간을 제외한다. 이를 다른 AF 유형이라고 명명하지 않는다.
- [VitalAgent 고정 버전](https://github.com/DKSEZD/VitalAgent/tree/f1800374f888587affec8381d4b37d21258f2ebc)의
  `agent/data/ppg_loader.py`, `ppg_window_labels.py`는 v2의 1을 AF로 보고
  주석 i를 QRS i부터 i+1까지 연결한다. 이 코드는 정수 변환을 하므로 분수 값 처리의
  정답 근거가 될 수 없다. 우리는 변환 전에 원본 실수 값을 비교한다.
- ECG 시작 시각과 QRSindex/500을 사용한다. MATLAB 1기반 가정으로 1을 뺀다.
  양쪽 한 RR 구간과 2ms를 추가로 확인하여 경계에 민감한 창을 제외한다.
  이 조치는 공식 시간 귀속 규칙 확인을 대체하지 않는다.
- QRS가 ECG 범위를 벗어난 참가자, PPG 시작 시간이 없거나 정렬 준비가 안 된 기록 제외.
- 39명 원본을 검토하되 평탄 신호 등의 제외로 실제 학습 인원은 줄어든다. audit.json에 기록.

## 재현과 평가

원래 준비 파일과 `y=-1`은 보존한다. 새 폴더에 10초/50Hz/500점 실험 자료를 만든다.
참가자·클래스당 최대 2,000개를 seed 42로 균등 추출한다. 긴 기록 한 사람이
실험 규모를 지배하지 않게 하는 첫 실험이며 전 구간 학습이라고 부르지 않는다.
MIMIC와 6종 자료의 기존 정답 변환은 유지한다.

학습/검증/평가는 참가자로 분리한다. MIMIC는 기존 분할을 유지하며 그 평가 대상은
이미 개발에서 본 이력이 있어 완전히 새로운 외부 검증이 아니다. 자료별 평가와
전체 평가를 함께 저장한다. 검증 BCE로 모델을 고르고 임계값은 0.5로 고정한다.
현재의 연구 사용 근거를 바탕으로 내부 실험을 하며 데이터/가중치 재배포 권한을
새로 주장하지 않는다. Git에는 코드와 설명만 올리고 원본/가중치는 올리지 않는다.

Colab에서 `prepare_af_provisional.py` 실행 후 `train_af_integrated.py --provisional`로
학습한다. 실제 결과는 Drive의 audit.json, split.json, config.json, history.json,
metrics.json으로 확인한다. 코드 업로드는 학습 완료를 의미하지 않는다.
