# 10초 PPG 최종 후보 개선 실험

## 변경 이유

기존 GPU 실험에서 손목 자료 단독 AUC도 약 0.513이었다. 자료 혼합이나
임계값 조정만으로 민감도 문제를 해결할 근거가 없어, PPG의 시간 관계를
입력으로 명시하는 두 후보를 비교한다. 기존 전처리 수정과 피험자 분할은 유지한다.

- 특징 모델: 자기상관(반복 주기의 유사성), 주파수 분포, 파형 변화량을 읽는다.
- 결합 모델: 위 특징과 10초 전체에 걸친 관계를 읽을 수 있는 확장 합성곱을 결합한다.
- 맥박 검출에 실패한 구간을 임의로 제외하지 않도록 이번 단계는 피크 검출 대신
  자기상관을 사용한다. 실제 맥박 간격 측정과 같다는 뜻은 아니다.

자기상관을 통한 손목 PPG AF 탐지의 선행 연구:
[Väliaho et al., 2021](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2021.654555/full).
이 구현은 해당 논문의 재현 모델이 아니라 별도의 개발 실험이다.

## 평가 기준과 제한

학습과 평가는 Colab GPU에서만 실행한다. 세 자료, 10초/50Hz, 같은 피험자
학습/검증 분할, 자료·클래스·피험자 균형 추출을 유지한다. 시험군은 후보 선택 중
읽지 않는다. ECG, 자료 출처, 피험자 식별자는 예측 입력에 넣지 않는다.

자료마다 다른 판정 기준을 적용하지 않는다. 검증군에서 **모든 자료의 특이도
80% 이상**을 만족하는 공통 임계값 중 자료별 민감도의 평균이 가장 높은 것을
선택한다. 같은 기준으로 체크포인트와 후보를 선택한다. 탐색 목표는 모든 자료에서
민감도 90%/특이도 80% 이상이며, 임상적으로 승인된 기준이 아니다. 목표 미달이면
그대로 보고하고 최종 완성 또는 문제 해결이라고 표현하지 않는다.

고주파 에너지 비율을 학습군 기준 사분위로 나눠 검증 성능과 AF 개수를 함께
기록한다. 이는 설명용 신호 특성일 뿐 검증된 품질 점수가 아니며, 어떤 구간도
이 기준으로 평가에서 버리지 않는다.

손목 정답은 기존의 잠정 exact 0/1 해석을 유지한다. 검증군을 여러 개발 실험에서
반복 사용하므로 결과는 개발 성능이다. 이미 살펴본 기존 시험군 결과도 새로운
외부 검증으로 주장할 수 없다. 임상 진단용 완성 모델로 선언하지 않는다.

## 실행과 저장

`python -u scripts/train_af_rhythm.py --base /content/drive/MyDrive/Capdyssey/af_integrated`

Drive의 `models/rhythm_candidates_v1`에 후보별 체크포인트, 재개 상태,
검증 예측, 특징 표준화 값, 공통 임계값, 비교 결과를 저장한다. 실행 중단 시
마지막 완료 epoch부터 재개한다. 원본 데이터와 가중치는 Git에 올리지 않는다.
실행 결과는 완료 확인 후 이 문서에 기록한다.
